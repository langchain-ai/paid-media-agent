# Open business questions

| Question | Why it matters | Default until resolved |
|---|---|---|
| Which platforms form the v1 support commitment? | Docs and tests must match real public availability | Google, Meta, and Reddit fixtures; verify live before release |
| Which common attribution inputs can users configure? | Cross-platform interpretation depends on windows and click/view semantics | Display platform facts and label incompatibility |
| Should a warehouse/CRM adapter ship in v1? | Business outcome quality is valuable but adds schema and privacy scope | Define an interface and fixture, not a production connector |
| Which mutations are safe enough for the first public canary? | Write breadth increases financial and operational risk | One reversible paused-state or budget operation after review |
| What report template ships as the default? | The public agent needs a useful artifact without company branding | Neutral accessible template with user-overridable theme tokens |
